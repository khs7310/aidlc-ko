# ASCII 다이어그램 표준

## 필수: 기본 ASCII만 사용

**중요**: 항상 다이어그램에 기본 ASCII 문자를 사용하십시오(최대 호환성).

### ✅ 허용됨: `+` `-` `|` `^` `v` `<` `>` 및 영숫자 텍스트

### ❌ 금지: 유니코드 상자 그리기 문자
- 아니요: `┌` `─` `│` `└` `┐` `┘` `├` `┤` `┬` `┴` `┼` `▼` `▲` `►` `◄`
- 이유: 글꼴/플랫폼 전반에 걸쳐 렌더링이 일관되지 않습니다.

## 표준 ASCII 다이어그램 패턴

### 중요: 문자 너비 규칙
**상자 안의 모든 줄은 정확히 동일한 문자 수(공백 포함)를 가져야 합니다**

✅ 정확함(모든 줄 = 67자):
```
+---------------------------------------------------------------+
|                      Component Name                           |
|  Description text here                                        |
+---------------------------------------------------------------+
```

❌ 잘못됨(일관되지 않은 너비):
```
+---------------------------------------------------------------+
|                      Component Name                           |
|  Description text here                                   |
+---------------------------------------------------------------+
```

### 박스 패턴
```
+-----------------------------------------------------+
|                                                     |
|              Calculator Application                 |
|                                                     |
|  Provides basic arithmetic operations for users     |
|  through a web-based interface                      |
|                                                     |
+-----------------------------------------------------+
```

```
+-------------------------------------------------------+
|              Web Server (PHP Runtime)                 |
|  +-------------------------------------------------+  |
|  |  index.php (Monolithic Application)             |  |
|  |  +-------------------------------------------+  |  |
|  |  |  HTML Template (View Layer)               |  |  |
|  |  |  - Form rendering                         |  |  |
|  |  |  - Result display                         |  |  |
|  |  +-------------------------------------------+  |  |
|  +-------------------------------------------------+  |
+-------------------------------------------------------+
```

### 화살표와 연결
```
+----------+
|  Source  |
+----------+
     |
     | HTTP POST
     v
+----------+
|  Target  |
+----------+
```

### 수평 흐름
```
+-------+     +-------+     +-------+
| Step1 | --> | Step2 | --> | Step3 |
+-------+     +-------+     +-------+
```

```
+----------+
```

## 확인

다이어그램을 만들기 전에:
- [ ] 기본 ASCII에만 해당: `+` `-` `|` `^` `v` `<` `>`
- [ ] 유니코드 상자 그리기 없음
- [ ] 정렬을 위한 공백(탭 아님)
- [ ] 코너 사용 `+`
- [ ] **모든 상자 줄은 동일한 문자 너비**(공백을 포함한 문자 수 계산)
- [ ] 테스트: 고정 폭 글꼴에서 모서리가 수직으로 정렬되는지 확인
