# 오류 처리 및 복구 절차

## 일반 오류 처리 원칙

### 오류가 발생하는 경우
1. **오류 식별**: 무엇이 잘못되었는지 명확하게 설명
2. **영향 평가**: 오류가 차단되고 있는지 아니면 해결할 수 있는지 확인합니다.
3. **의사소통**: 사용자에게 오류 및 옵션에 대해 알립니다.
4. **해결책 제안**: 오류를 해결하기 위한 명확한 단계를 제공합니다.
5. **문서**: `audit.md`에 오류 및 해결 방법을 기록합니다.

### 오류 심각도 수준

**중요**: 워크플로를 계속할 수 없습니다.
- 필수 파일 또는 아티팩트 누락
- 처리할 수 없는 잘못된 사용자 입력
- 파일 작업을 방해하는 시스템 오류

**높음**: 계획대로 단계를 완료할 수 없습니다.
- 필수 질문에 대한 불완전한 답변
- 모순되는 사용자 응답
- 이전 단계의 종속성 누락

**중간**: 해결 방법을 통해 단계를 계속할 수 있습니다.
- 선택적 아티팩트가 누락되었습니다.
- 중요하지 않은 검증 실패
- 부분완료 가능

**낮음**: 진행을 방해하지 않는 사소한 문제
- 형식 불일치
- 선택적 정보가 누락되었습니다.
- 비차단 경고

## 단계별 오류 처리

### 작업공간 감지 오류

**오류**: 작업공간 파일을 읽을 수 없습니다.
- **원인**: 권한 문제, 디렉터리 누락
- **해결책**: 사용자에게 작업공간 경로 및 권한을 확인하도록 요청
- **해결 방법**: 사용자가 제공한 정보만 사용하여 진행하세요.

**오류**: 기존 `aidlc-state.md`이 손상되었습니다.
- **원인**: 수동 편집, 불완전한 이전 실행
- **해결책**: 사용자에게 새로 시작할 것인지 아니면 복구를 시도할 것인지 물어보세요.
- **복구**: 백업 생성, 새 상태 파일 시작

**오류**: 필수 단계를 결정할 수 없습니다.
- **원인**: 사용자의 정보가 부족함
- **해결책**: 의도와 범위에 대해 명확한 질문을 하세요.
- **해결 방법**: 기본적으로 포괄적인 실행 계획

### 요구사항 분석 오류

**오류**: 사용자가 모순되는 요구사항을 제공했습니다.
- **원인**: 불분명한 이해, 변화하는 요구
- **해결책**: 모순을 해결하기 위한 후속 질문 만들기
- **진행하지 마세요**: 모순이 해결될 때까지

**오류**: 요구사항 문서를 변환할 수 없습니다.
- **원인**: 지원되지 않는 형식, 손상된 파일
- **해결책**: 사용자에게 지원되는 형식으로 요구사항을 제공하도록 요청하세요.
- **해결 방법**: 사용자의 구두 설명 작업

**오류**: 확인 질문에 대한 답변이 불완전합니다.
- **원인**: 사용자가 질문을 건너뛰고 무엇에 대답해야 할지 불분명함
- **해결책**: 답변되지 않은 질문을 강조하고 예시를 제공하세요.
- **계속하지 마세요**: 모든 필수 질문에 답변될 때까지

### 사용자 스토리 오류

**오류**: 요구 사항을 스토리에 매핑할 수 없습니다.
- **원인**: 요구사항이 너무 모호하고 기능적 세부정보가 누락되었습니다.
- **해결책**: 명확성을 위해 요구사항 분석으로 돌아가기
- **해결 방법**: 사용 가능한 정보를 기반으로 스토리를 만들고 미완료로 표시합니다.

**오류**: 사용자가 모호한 스토리 계획 답변을 제공합니다.
- **원인**: 불분명한 옵션, 복잡한 결정
- **해결책**: 구체적인 예가 포함된 후속 질문을 추가하세요.
- **진행하지 마세요**: 모호성이 해결될 때까지

**오류**: 스토리 생성 계획에 완료되지 않은 단계가 있습니다.
- **원인**: 실행이 중단되고 단계를 건너뛰었습니다.
- **해결책**: 완료되지 않은 첫 번째 단계부터 재개
- **복구**: 완료된 단계를 검토하고 체크포인트부터 계속합니다.

### 애플리케이션 디자인 오류

**오류**: 아키텍처 결정이 불분명하거나 모순됩니다.
- **원인**: 모호한 답변, 상충되는 요구 사항
- **해결책**: 결정을 명확히 하기 위해 후속 질문을 추가하세요.
- **계속하지 마세요**: 결정이 명확하고 문서화될 때까지

**오류**: 서비스/단위 수를 확인할 수 없습니다.
- **원인**: 경계에 대한 정보가 부족함
- **해결책**: 배포, 팀 구조, 확장에 대해 구체적으로 질문하세요.
- **해결 방법**: 기본값은 모놀리스로, 나중에 변경 허용

### 설계 오류

**오류**: 단위 종속성은 순환적입니다.
- **원인**: 잘못된 경계 정의, 긴밀한 결합
- **해결책**: 순환 종속성 식별, 리팩토링 제안
- **복구**: 주기를 깨기 위해 단위 경계를 수정합니다.

**오류**: 단위 설계 계획에 단계가 누락되었습니다.
- **원인**: 계획 생성 미완료, 템플릿 오류
- **해결책**: 필요한 모든 단계를 포함하여 계획을 다시 생성하세요.
- **복구**: 기존 계획에 누락된 단계 추가

**오류**: 디자인 아티팩트를 생성할 수 없습니다.
- **원인**: 단위 정보 누락, 불명확한 요구 사항
- **해결책**: 단위 생성으로 돌아가서 단위 정의를 명확히 합니다.
- **해결 방법**: 부분 디자인 생성, 간격 표시

### NFR 구현 오류

**오류**: 기술 스택 선택이 호환되지 않습니다.
- **원인**: 요구사항 충돌, 플랫폼 제한
- **해결책**: 비호환성을 강조하고 사용자에게 선택하도록 요청
- **계속하지 마세요**: 호환되는 선택이 이루어질 때까지

**오류**: 조직 제약 조건을 충족할 수 없습니다.
- **원인**: 네트워크 제한, 보안 정책
- **해결책**: 문서 제약 조건, 사용자에게 해결 방법 요청
- **에스컬레이션**: 설정을 위해 사람의 개입이 필요할 수 있습니다.

**오류**: NFR 구현 단계에는 사람의 작업이 필요합니다.
- **원인**: AI는 특정 작업(네트워크 구성, 자격 증명)을 수행할 수 없습니다.
- **해결책**: **인간 작업**으로 명확하게 표시하고 지침을 제공합니다.
- **대기**: 진행하기 전 사용자 확인을 위해

### 코드 생성 계획 오류

**오류**: 코드 생성 계획이 불완전합니다.
- **원인**: 디자인 아티팩트 누락, 불명확한 요구사항
- **해결책**: 설계 단계로 돌아가 아티팩트 완성
- **복구**: 사용 가능한 정보로 계획을 생성하고 공백을 표시합니다.

**오류**: 단위 종속성이 충족되지 않았습니다.
- **원인**: 종속 단위가 아직 생성되지 않았습니다.
- **해결책**: 종속성을 존중하도록 생성 순서를 다시 정렬합니다.
- **해결 방법**: 스텁 종속성을 사용하여 생성하고 나중에 통합

### 코드 생성 오류(2부: 코드 생성)

**오류**: 단계에 대한 코드를 생성할 수 없습니다.
- **원인**: 설계 정보 부족, 요구사항 불분명
- **해결책**: 단계를 건너뛰고 문서를 불완전한 것으로 보고 계속합니다.
- **복구**: 추가 정보 수집 후 단계로 돌아갑니다.

**오류**: 생성된 코드에 구문 오류가 있습니다.
- **원인**: 템플릿 문제, 언어별 문제
- **해결책**: 구문 오류를 수정하고 필요한 경우 다시 생성하세요.
- **검증**: 진행하기 전에 코드 컴파일을 확인하세요.

**오류**: 테스트 생성 실패
- **원인**: 복잡한 로직, 테스트 프레임워크 설정 누락
- **해결책**: 기본 테스트 구조 생성, 수동 완료 표시
- **해결 방법**: 테스트 없이 진행하고 작업 단계에 추가하세요.

### 작업 오류

**오류**: 빌드 도구를 확인할 수 없습니다.
- **원인**: 비정상적인 프로젝트 구조, 다중 빌드 시스템
- **해결책**: 사용자에게 빌드 도구 및 명령을 지정하도록 요청
- **해결 방법**: 일반적인 지침을 제공하고 사용자가 조정합니다.

**오류**: 배포 대상이 불분명합니다.
- **원인**: 다양한 환경, 복잡한 인프라
- **해결 방법**: 사용자에게 배포 대상 및 방법을 지정하도록 요청
- **해결 방법**: 일반 플랫폼에 대한 지침 제공

## 복구 절차

### 부분 단계 완료

**시나리오**: 실행 도중 단계가 중단되었습니다.

**복구 단계**:
1. 무대 계획 파일 로드
2. 마지막으로 완료된 단계 식별(마지막 [x] 확인란)
3. 완료되지 않은 다음 단계부터 재개
4. 모든 이전 단계가 실제로 완료되었는지 확인
5. 정상적으로 계속 실행

### 손상된 상태 파일

**시나리오**: `aidlc-state.md`이 손상되었거나 일관성이 없습니다.

**복구 단계**:
1. 백업 만들기: `aidlc-state.md.backup`
2. 사용자에게 실제로 어느 단계에 있는지 물어보세요.
3. 상태 파일을 처음부터 다시 생성
4. 기존 아티팩트를 기반으로 완료된 단계 표시
5. 현재 단계부터 재개

### 누락된 유물

**시나리오**: 이전 단계의 필수 아티팩트가 누락되었습니다.

**복구 단계**:
1. 누락된 아티팩트 식별
2. 재생성 가능한지 확인
3. 그렇다면: 해당 단계로 돌아가서 아티팩트를 재생성합니다.
4. 아니요인 경우: 사용자에게 정보를 수동으로 제공하도록 요청합니다.
5. `audit.md`의 공백을 문서화하세요.

### 사용자가 스테이지를 다시 시작하려고 함

**시나리오**: 사용자가 단계 결과에 만족하지 않아 다시 실행하고 싶어함

**복구 단계**:
1. 사용자가 다시 시작하기를 원하는지 확인하세요. (데이터는 손실됩니다.)
2. 기존 아티팩트 보관: `{artifact}.backup`
3. `aidlc-state.md`의 단계 상태 재설정
4. 계획 파일의 단계 확인란 지우기
5. 단계를 처음부터 다시 실행

### 사용자가 단계를 건너뛰고 싶어함

**시나리오**: 사용자가 계획된 단계를 건너뛰기를 원합니다.

**복구 단계**:
1. 사용자가 의미를 이해했는지 확인
2. `audit.md`의 문서 건너뛰기 이유
3. `aidlc-state.md`에서 단계를 '건너뛰기'로 표시
4. 다음 단계로 진행
5. 참고: 종속성이 누락되면 이후 단계에서 문제가 발생할 수 있습니다.

## 에스컬레이션 지침

### 사용자에게 도움을 요청해야 하는 경우

**즉시**:
- 모순되거나 모호한 사용자 입력
- 필수 정보가 누락되었습니다.
- AI가 해결할 수 없는 기술적 제약
- 비즈니스 판단이 필요한 결정

**해결 시도 후**:
- 같은 단계에서 반복되는 오류
- 복잡한 기술 문제
- 특이한 프로젝트 구조
- 외부 시스템과의 통합

### 처음부터 다시 시작하라고 제안하는 경우

**다음과 같은 경우 새로 시작을 고려하세요**:
- 여러 단계에 오류가 있습니다.
- 상태 파일이 심각하게 손상되었습니다.
- 사용자 요구 사항이 크게 변경되었습니다.
- 아키텍처 결정을 뒤집어야 합니다.
- 사용자는 누락된 정보를 제공할 수 없습니다.
- 아티팩트가 여러 단계에서 일관되지 않습니다.

**다시 시작하기 전에**:
1. 기존 작업 모두 보관
2. 배운 내용을 문서화하세요.
3. 보존할 항목 식별
4. 사용자 확인 받기
5. 새 실행 계획 만들기

## 세션 재개 오류

### 재개 중 아티팩트 누락

**오류**: 이전 단계의 필수 아티팩트가 누락되었습니다.
- **원인**: 파일이 삭제, 이동되었거나 생성되지 않았습니다.
- **해결책**:
  1. 누락된 아티팩트가 생성된 단계 식별
  2. aidlc-state.md에서 단계가 완료로 표시되었는지 확인하세요.
  3. 완료로 표시되었지만 아티팩트가 누락된 경우: 해당 단계를 다시 생성합니다.
  4. 완료로 표시되지 않은 경우: 해당 단계부터 재개
- **복구**: 누락된 아티팩트를 생성하는 단계로 돌아가서 재실행

**오류**: 아티팩트 파일이 존재하지만 비어 있거나 손상되었습니다.
- **원인**: 쓰기 중단, 수동 편집, 파일 시스템 문제
- **해결책**:
  1. 손상된 파일의 백업 생성
  2. 그것을 생성한 단계에서 재생성 시도
  3. 재생성할 수 없는 경우: 사용자에게 재생성에 필요한 정보를 요청합니다.
- **복구**: 아티팩트를 생성한 단계를 다시 실행합니다.

### 재개 중 일관되지 않은 상태

**오류**:aidlc-state.md에는 단계 완료가 표시되지만 아티팩트가 존재하지 않습니다.
- **원인**: 상태 파일이 업데이트되었지만 아티팩트 생성에 실패했습니다.
- **해결책**:
  1. aidlc-state.md에서 단계를 불완전한 것으로 표시
  2. 스테이지를 다시 실행하여 아티팩트 생성
  3. 완료로 표시하기 전에 아티팩트가 존재하는지 확인하세요.
- **Recovery**: 단계 상태를 재설정하고 재실행

**오류**: 아티팩트가 존재하지만aidlc-state.md에 단계가 불완전하다고 표시됩니다.
- **원인**: 아티팩트 생성은 성공했지만 상태 업데이트는 실패했습니다.
- **해결책**:
  1. 아티팩트가 완전하고 유효한지 확인하세요.
  2. 단계 완료를 표시하려면aidlc-state.md를 업데이트하세요.
  3. 다음 단계로 진행
- **복구**: 실제 완료를 반영하도록 상태 파일을 업데이트합니다.

**오류**:aidlc-state.md에 "현재"로 표시된 여러 단계
- **원인**: 상태 파일 손상, 수동 편집
- **해결책**:
  1. 아티팩트를 검토하여 실제 진행 상황 확인
  2. 사용자에게 실제로 어느 단계에 있는지 물어보세요.
  3. 단일 현재 단계를 표시하도록 aimlc-state.md를 수정하세요.
- **복구**: 기존 아티팩트를 기반으로 상태 파일 재구축

### 컨텍스트 로딩 오류

**오류**: 이전 단계에서 필수 컨텍스트를 로드할 수 없습니다.
- **원인**: 파일 누락, 콘텐츠 손상, 잘못된 파일 경로
- **해결책**:
  1. 현재 단계에 필요한 아티팩트 나열
  2. 누락되거나 손상된 항목을 확인하세요.
  3. 누락된 아티팩트를 재생성하거나 사용자에게 정보를 요청하세요.
- **복구**: 현재 단계를 재개하기 전에 전제 조건 단계를 완료하세요.

**오류**: 로드된 아티팩트에 모순되는 정보가 포함되어 있습니다.
- **원인**: 수동 편집, 여러 사람 작업, 불완전한 업데이트
- **해결책**:
  1. 모순을 식별하고 사용자에게 제시
  2. 사용자에게 어떤 정보가 올바른지 물어보세요.
  3. 모순을 해결하기 위해 아티팩트 업데이트
- **복구**: 진행하기 전에 모순을 조정하세요.

### 재개 모범 사례

1. **항상 상태 유효성 검사**:aidlc-state.md가 실제 아티팩트와 일치하는지 확인하세요.
2. **증분식 로드**: 아티팩트를 단계별로 로드하고 각 유효성을 검사합니다.
3. **빠른 실패**: 중요한 아티팩트가 누락된 경우 즉시 중지
4. **명확하게 의사소통**: 사용자에게 누락된 내용과 필요한 이유를 정확하게 알려줍니다.
5. **제공 옵션**: 재생성, 수동 제공 또는 새로 시작
6. **문서 복구**: audit.md에 모든 복구 작업을 기록합니다.
